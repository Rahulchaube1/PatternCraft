# Contributing to PatternCraft 🚀

Thank you for your interest in contributing to **PatternCraft: The Architectural Blueprint to Software Design Patterns**!

PatternCraft is an open-source, visual, and practical software design patterns guide designed to help developers, software architects, and engineering teams master clean architecture, robust system design, and the 23 Gang of Four (GoF) patterns without academic fluff.

---

## 🌟 How You Can Help

We welcome contributions across all areas:
1. **Language Implementations:** Adding idiomatic implementations in TypeScript, Python, Go, Rust, Java, C#, or Kotlin.
2. **Diagram Enhancements:** Proposing improved Mermaid UML sequence or class diagrams.
3. **Real-World Case Studies:** Adding verified industry precedents and production architectural trade-offs.
4. **Translations:** Translating PatternCraft into Spanish, Mandarin, Japanese, Hindi, German, etc.
5. **Typo Fixes & Clarity Improvements:** Refining explanations to make them even clearer.

---

## 🛠️ Contribution Workflow

1. **Fork the Repository:**
   Click the **Fork** button at the top right of [github.com/Rahulchaube1/PatternCraft](https://github.com/Rahulchaube1/PatternCraft).

2. **Clone your fork locally:**
   ```bash
   git clone https://github.com/<your-username>/PatternCraft.git
   cd PatternCraft
   ```

3. **Create a descriptive feature branch:**
   ```bash
   git checkout -b feature/add-typescript-strategy-pattern
   ```

4. **Adhere to the Pattern Structure:**
   When adding or refining a pattern, follow PatternCraft's standard 7-part anatomy:
   - **📌 Intent:** Formal GoF definition in 1 clear sentence.
   - **🌍 Real-World Analogy:** Relatable everyday scenario.
   - **🎯 Problem & Motivation:** Code smell / anti-pattern without the pattern.
   - **📐 Architecture & Diagram:** Crisp Mermaid diagram.
   - **💻 Production-Grade Code:** Strongly-typed, clean, production-ready snippet.
   - **⚖️ Trade-offs & Analysis:** Advantages, Disadvantages, When to use, When NOT to use.
   - **🏢 Industry Precedents:** Production framework examples (e.g. Spring, React, Linux).

5. **Commit your changes with clear messages:**
   ```bash
   git commit -m "docs: enrich command pattern with real-world undo/redo queue example"
   ```

6. **Push to your fork and submit a PR:**
   ```bash
   git push origin feature/add-typescript-strategy-pattern
   ```
   Open a Pull Request against `main` on `Rahulchaube1/PatternCraft`.
